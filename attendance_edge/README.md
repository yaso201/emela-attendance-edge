# attendance_edge

Frappe edge app for LaNEM attendance local capture.

This app is the P0 skeleton required by `specifications/attendance/D4-v1.1-TODO-Developpement-Attendance.md`.
It is intended for the local attendance site, not for direct installation on the central campus/backoffice sites.

The P1 implementation will add the local attendance DocTypes and services described in D4.
